# Boat Lettering Service

South Florida boat lettering shop site — names, graphics, wraps, and DIY striping. Next.js + Tailwind.

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Pages

- `/` Home
- `/portfolio` Gallery
- `/design` Live lettering designer
- `/striping` 150 ft stripe rolls
- `/contact` Quote form
- `/sitemap` HTML sitemap

Old `.html` URLs redirect to these routes.

## Forms

Copy `.env.example` to `.env.local` and add a [Web3Forms](https://web3forms.com/) key to email `boatlettering1@yahoo.com`. Without a key, submit opens a prefilled email.

## Brand files

Drop a logo in `public/brand/` and job photos in `public/portfolio/`.
